# GameLab — wariant A

Zatwierdzony przez użytkownika: silnik JavaScript wewnątrz iframe, 10 lekcji i 20 różnych zadań (prowadzone + samodzielne). Bez nowych zależności ani backendu. Wzorzec API i konsoli: C:/Nauka/java-lab.

Pliki ucznia: pełny index.html, jeden styles.css, game.js oraz własne komponenty JS dodawane przyciskiem Dodaj plik. Silnik wstrzykiwany przez sandbox udostępnia Game, GameObject, Component, Transform, Input, Time, Canvas, ShapeRenderer, Sprite, Collider2D, Trigger2D i CharacterController2D. Pozycja oznacza środek obiektu. Cykl: onCreate, onUpdate(delta), onDestroy.

Lekcje 701–710: canvas, czas, obiekty, komponenty, input, ruch/granice, sprite, kolizje, stan/HUD, gra końcowa. Każde zadanie wymaga innego zachowania. Sprawdzenie uruchamia deterministyczne scenariusze z klawiaturą, czasem i rozmiarem; odczytuje stan obiektów i polecenia rzeczywiście renderowane na canvasie. Starter i rozwiązanie poprzedniego zadania nie zaliczają kolejnego.

Konsola pod edytorem, terminalowy wygląd i status. Podgląd gry po prawej, pełny ekran bez restartu, fokus klawiatury, reset wejścia po blur, zatrzymanie i sprzątanie pętli przy zmianie projektu. Auto-podgląd/Ctrl+S działają jak w innych kursach.
